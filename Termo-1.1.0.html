Termo 1.1.0

release: 1.1.0（构建号 35）

新增 SSH Agent 认证：可直接使用 1Password、Secretive、系统 ssh-agent 中的密钥登录，私钥不经过 Termo；可在「设置 › 安全」指定 Agent 套接字（自动识别已安装的 1Password / Secretive），单台主机也可单独指定（#3）
修复 vim / top 等全屏程序只占半屏、换行错乱：终端连上之前的尺寸变化未同步给远端（#5）
修复终端 ⌘C / ⌘V 失效、鼠标拖选时选区突然断开；改变窗口大小时远端提示符反复重绘造成的输出错乱（#2）
终端新增 GPU（Metal）渲染并默认开启，可在「设置 › 终端」关闭；大量输出时合并刷新并限流，Ctrl+C 能及时生效
拖动窗口大小、拖动侧栏时终端不再逐帧重排，松手后一次性调整到位
所有弹窗支持点击空白处关闭；设置、新增主机、端口转发等面板改为窗口内弹窗
「设置 › 快捷键」中列出的 ⌘T / ⌘W / ⌘B / ⌃Tab / ⌘+ / ⌘- 现已生效，新增 ⌘, 打开设置
主机的代理（SOCKS5 / SOCKS4 / HTTP）、加密算法、连接超时、终端显示编码设置恢复生效（此前被忽略、实际为直连）
安全：首次连接的主机在核对指纹前不再发送密码/密钥（监控、探测、文件、端口转发、测试连接均已覆盖）；修复 known_hosts 只记录了其它类型密钥时被误判为「疑似中间人」
修复 SFTP 保存文件后属主被改为当前用户、软链接被替换为普通文件；GBK 等非 UTF-8 文件保存后被转成 UTF-8
修复备用通道读写大文件时可能被截断；取消删除目录后远端仍继续删除；修改权限会清掉 setuid/setgid/粘滞位
修复动态端口转发（SOCKS5）无法使用、隧道偶发卡死、停止转发时界面卡顿，以及网络切换后重复启动导致隧道被停掉
修复转发运行期间托盘与界面动画持续占用 CPU；概览页网速图、主机列表、标签栏、编辑器打字等多处卡顿
修复下载到已满磁盘或被拔出的外接盘时应用闪退；浏览器经端口转发中途取消下载时应用退出
文件浏览、目录树、编辑器按主机共用一条 SFTP 连接，打开文件不再每次重新建连认证；连接出错后自动重建，不再永久降级为慢速通道
端口转发改为全异步处理：慢客户端、迟迟不响应的目标不再卡住同一隧道里的其它连接；空闲隧道不再预占内存
主机设置里的「心跳间隔」恢复生效：终端空闲时按间隔发心跳，断网后十几秒内即提示并自动重连
修复弹窗里的输入框无法用 ⌘C / ⌘V / ⌘X / ⌘A / ⌘Z 复制粘贴、全选、撤销
所有弹窗支持按 Esc 关闭（效果同点击空白处）；弹窗打开时按 Tab 不再跳到背后的搜索框；多层弹窗叠加时背景不再越压越黑
输入框的占位文字改为浅色，不再和已填写的内容混淆；浅色模式下次要文字、图标、文件类型图标的对比度提高
统一按钮样式：高度与输入框对齐，带悬停与按下反馈，禁用状态一眼可辨；主按钮颜色加深，白字更清晰
删除密钥、代码片段前先确认（密钥会提示仍在使用它的主机）；退出时如有未保存的文件会先提示
新增 / 编辑主机：端口、超时、心跳填写不合法时不能保存，并在底部说明原因（此前会被悄悄改成默认值）
侧栏：搜索框可一键清除、按 Esc 清空，无结果时可直接清除搜索；搜索时折叠的分组自动展开；切换分区时清空搜索；侧栏宽度会被记住
主机列表：离线主机显示红点，与「尚未探测」区分；长名称不再折行；右键菜单新增「复制地址」；RDP 主机也显示延迟
标签栏：标题过长时截断并可悬停查看全名，同名文件附上所在目录；右键菜单新增「关闭右侧标签」
菜单栏补齐 ⌘H 隐藏、⌘M 最小化、⌃⌘F 全屏等系统标准项，新增 ⌘1–⌘9 切换标签
终端断线提示如实显示「等待网络」「N 秒后重连」「正在重连」；密码错误、主机指纹不符等情况不再无限重试，直接说明原因；可直接关闭标签
终端 ⌘K 清屏只清屏幕和回滚区并保留当前提示符，不再重置终端模式（此前在 vim / tmux 里按会导致键鼠错乱）
远程桌面断线后显示提示并可一键重新连接，不再停在最后一帧
文件浏览器支持方向键、回车打开、⌘⌫ 删除、⌘↑ 上一级、⌘[ 后退、⌘A 全选；指向目录的软链接可直接进入；出错后「重试」会重试失败的那个目录
编辑器：有未保存修改时点「重新加载」会先确认；超出打开上限的文件直接提示并可下载到本地；保存时按钮不再跳动
下载完成后可「在访达中显示」；同时拖入文件和文件夹时会提示被跳过的文件夹
主机监控在连接中断时会标出「数据已停止更新」并淡化旧数据；内存、磁盘按 1024 进位显示
悬停提示改为自定义样式（替换残留的系统提示），点击或切换应用时立即消失
